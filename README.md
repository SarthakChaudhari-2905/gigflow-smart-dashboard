# GigFlow – Smart Leads Dashboard

A full-stack MERN application for managing sales leads with authentication, lead tracking, filtering, analytics dashboard, and responsive UI.

## ✨ Features

- User Authentication (JWT)
- Register/Login System
- Protected Routes
- Add Leads
- Edit Leads
- Delete Leads
- Search Leads
- Filter Leads by Status
- Dashboard Analytics
- Responsive UI
- Toast Notifications
- Zustand State Management

---

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM
- Zustand
- React Toastify

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcryptjs

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone YOUR_GITHUB_REPO_LINK
```

---

# Backend Setup

```bash
cd backend
npm install
```

Create `.env`

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
```

Run Backend

```bash
npm run dev
```

---

# Frontend Setup

```bash
cd frontend
npm install
```

Create `.env`

```env
VITE_API_URL=your_backend_url/api
```

Run Frontend

```bash
npm run dev
```
